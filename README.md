# led-controller

電飾用LEDテープ制御基板設計

## 実現したいこと

ESP32S3 x Flutter(Android)のBLE通信が可能なアプリを構築し、アプリからLEDテープのカラー点灯制御をする。
通信自体はアプリからESPに一方的な通信ができれば十分。

具体的な機能↓
- 色のプリセットを用意してワンボタンで光るようにする
- 色の明るさが調整できる
- ゲーミング化できるようにする

## LEDテープの仕様

12Vの電源端子とRGBそれぞれの端子があり内部信号は把握していない

## できたら実装したい

スマホ一台から複数のESPと通信し、LEDの点灯制御をしたい
